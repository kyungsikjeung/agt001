## 2. 카테고리 30종 구성표

> 읽는 법: `부품`은 우리 렌더러 섹션 타입과 1:1이다
> (hero/intro/offerings/gallery/contact/cta/reviews/video/features/stats/around/form).
> `필수 데이터`가 비면 공개본에서 숨겨지므로, 요구사항 질문과 직결된다.

### 가게 A. 펜션·숙박 (A1~A5)

| # | 카테고리 | 대표 부품 순서 | 필수 데이터 | 구성 메모 |
|---|---|---|---|---|
| A1 | 일반 펜션 | hero(객실 사진) → 객실 소개 → 편의(바비큐·취사) → 요금 → 오시는 길 → 예약 문의 | 객실 수·종류, 바비큐 유무, 체크인아웃, 전화 | 바비큐·주변 맛집이 전환 핵심. 실사례: 객실+바비큐+주변안내+전화예약 구조 |
| A2 | 풀빌라·독채 | hero(풀 사진) → 독채 안내 → 요금(성수기) → 후기 → 예약 | 독채 여부, 수영장, 기준/최대 인원, 요금 | 요금표가 없으면 문의 폭주. 가격 심화 필수 |
| A3 | 게스트하우스 | hero → 객실(도미토리·개인실) → 공용공간 → 찾아오는 길 → 예약 | 침대 단가(25,000원~ 표기), 체크인 시간, 전화 | 1박 단가·체크인아웃 표가 핵심 (실사례: BED PRICE 표) |
| A4 | 캠핑·글램핑 | hero(외경) → 사이트 종류 → 대여품목 → 요금 → 예약·문의 | 사이트 수, 대여료, 입퇴실, 전화 | 대여품목이 offerings, 요금은 별도 표 |
| A5 | 한옥스테이 | hero → 객실 → 체험(다도 등) → 주변 관광 → 예약 | 객실 수, 체험 유무, 요금, 주소 | 체험=sections, 관광=around |

### 가게 B. 카페·디저트 (B1~B4)

| # | 카테고리 | 대표 부품 순서 | 필수 데이터 | 구성 메모 |
|---|---|---|---|---|
| B1 | 일반 카페 | hero(대표 메뉴 사진) → 대표 메뉴 → 매장 소개 → 영업시간 → 오시는 길 | 대표 메뉴 2~3개, 영업시간, 주소 | 메뉴+가격 분리(N-2)가 여기서効く |
| B2 | 디저트·베이커리 | hero(상품 사진) → 상품 목록 → 가격 → 주문 방법 → 매장 안내 | 상품명·가격, 예약·주문 수단 | 상품 수가 많으면 gallery 병행 |
| B3 | 브런치·브런치카페 | hero → 메뉴(시간대별) → 가격 → 예약 → 오시는 길 | 모닝/런치 구분, 가격, 예약 URL | 시간대 메뉴가 offerings분리 대상 |
| B4 | 테이크아웃 전문 | hero → 메뉴·가격 → 주문(전화·앱) → 위치 | 메뉴·가격, 전화번호 | CTA를 전화 주문 1개로 |

### 가게 C. 식당 (C1~C5)

| # | 카테고리 | 대표 부품 순서 | 필수 데이터 | 구성 메모 |
|---|---|---|---|---|
| C1 | 한식·백반 | hero(대표 메뉴) → 메뉴·가격 → 매장 소개 → 영업시간 → 오시는 길 | 메뉴·가격, 영업시간, 주차 | 메뉴 스크롤 등장(2026 식당 트렌드) |
| C2 | 고깃집 | hero(고기 사진) → 메뉴·가격(부위별) → 단체 예약 → 주차 → 문의 | 부위·가격, 단체석, 주차 | 단체 예약을 숨은 항목이 아닌 섹션으로 |
| C3 | 일식·중식·양식 | hero → 코스·단품 → 가격 → 예약 → 오시는 길 | 코스 구성, 가격대, 예약 수단 | 코스는 offerings 1묶음+가격 |
| C4 | 분식·주점 | hero → 메뉴·가격 → 포장·배달 → 영업시간 | 메뉴·가격, 포장 여부, 전화 | 포장·배달=숨은 항목→아이콘 칸 |
| C5 | 치킨·피자 | hero → 메뉴·가격 → 배달·포장 → 후기 | 메뉴·가격, 배달 수단, 전화 | 주문 CTA를 최상단 sticky |

### 가게 D. 미용·뷰티 (D1~D4)

| # | 카테고리 | 대표 부품 순서 | 필수 데이터 | 구성 메모 |
|---|---|---|---|---|
| D1 | 헤어 미용실 | hero(스타일 사진) → 시술 메뉴 → 디자이너 → 가격표 → 예약 → 후기 | 시술명·소요시간·가격, 디자이너별 가격, 예약 수단 | **가격표는 디자이너 등급×시술 매트릭스**가 실표준. 디자이너 지정·당일 예약이 핵심 (실사례 8건이 전부 이 구조) |
| D2 | 네일 | hero → 시술 메뉴 → 가격 → 예약 → 갤러리 | 아트 종류·가격, 소요시간, 예약 수단 | 갤러리(시술 사진)가 전환 핵심 |
| D3 | 피부·왁싱·속눈썹 | hero → 시술 → 가격·횟수권 → 예약 → 주의사항 | 코스·횟수권가, 예약 수단 | 횟수권=price 여러 값 |
| D4 | 바버·남성 전문 | hero → 메뉴 → 가격 → 예약 | 메뉴·가격, 예약 수단 | 남성 전용 메뉴를 숨은 항목이 아닌 섹션으로 |

### 가게 E. 공방·클래스 (E1~E3)

| # | 카테고리 | 대표 부품 순서 | 필수 데이터 | 구성 메모 |
|---|---|---|---|---|
| E1 | 도자기·가죽·목공 | hero(작품) → 수업(원데이·정규) → 가격 → 신청 → 오시는 길 | 수업 종류·가격, 준비물, 신청 수단 | 준비물 안내=숨은 항목→아이콘 칸 |
| E2 | 플라워·캔들·향수 | hero → 클래스 → 가격 → 신청 | 클래스·가격, 신청 수단 | 작품 사진첩이 핵심 |
| E3 | 쿠킹·베이킹 | hero → 클래스 → 가격·일정 → 신청 | 일정·가격, 신청 수단 | 일정표=sections |

## 3. 구성 원칙 도출표 (30종 공통 → 시안 규칙)

| 원칙 | 내용 | 반영처 |
|---|---|---|
| P1 | 첫 화면=사진 or 굵은 제목 + CTA 1개(전화·예약·문의) | hero |
| P2 | 메뉴·가격은 쌍으로. 가격 모르면 "가격 문의"로 (지어내지 않음) | offerings + price |
| P3 | 예약·채널은 주소(URL) 없으면 버튼을 빼거나 숨김 (더미 금지) | contact/cta + V2-3 |
| P4 | 등급×항목 매트릭스(미용실·학원)는 표 부품으로 | price_list |
| P5 | 실문구 후기·FAQ는 전환 부품. 없는 말은 만들지 않음 | reviews |
| P6 | 숨은 항목(주차·당일·체험 등)은 아이콘 칸으로 | features icons |
| P7 | 3안은 역할 고정: ① 정석 ② 분위기 ③ 대비 (D43) | variants |
