# 개인정보처리방침에 덧붙일 문단 초안 (온라인 주문·스탬프)

> 초안 — 법률 검토(L1~L6) 전, 대표 승인 전 게시 금지.
> 이 파일은 `static/privacy.html`에 그대로 넣지 마세요.
> 대표가 승인하면 Claude가 방침 본문에 옮깁니다.

아래 문단은 지금 방침의 번호 체계(1~10항)에 맞춰 넣을 자리와 함께 적었습니다.
말투는 본문과 같이 "합니다"체로 썼습니다.

## 1항 표에 더할 행 (수집하는 개인정보 항목)

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 온라인 주문 (이 서비스로 만든 사이트의 "주문하기" 양식) | 이름(선택)·전화번호·주문 내용(메뉴·수량). 양식 아래에 수집 목적을 한 줄로 알림 (확인 필요: 문의·예약 양식처럼 고지만으로 충분한지, 동의 체크가 필요한지 — 지금 양식에는 동의 체크가 없음) | 손님이 직접 입력. 해당 가게의 채팅방에 전달 |
| 스탬프·쿠폰 | 전화번호·도장 기록(주문당 적립·환불 시 회수·사장님 수동 적립)·쿠폰 번호·사용 시각 | 결제 확정·사장님 수동 적립·쿠폰 사용 때 자동 생성 |

## 2항 표에 더할 행 (수집·이용 목적)

| 목적 | 이용 항목 |
|---|---|
| 만든 사이트의 주문 전달 | 온라인 주문(이름·전화번호·주문 내용)을 해당 채팅방에 알림으로 전달 |
| 스탬프 적립·쿠폰 주기 | 전화번호로 도장을 쌓고, 목표를 채우면 쿠폰 번호를 줌. 사장님의 쿠폰 사용 확인 |

## 3항 표에 더할 행 (보관 기간과 파기)

| 항목 | 보관 기간 | 파기 방법·비고 |
|---|---|---|
| 온라인 주문·결제 기록 | [대표 결정 Q2] | 기간이 끝나면 자동 삭제. 채팅방에 전달된 알림 메시지는 채팅방 보관 정책을 따름 |
| 스탬프·쿠폰 기록 | [대표 결정 Q2] | 기간이 끝나면 자동 삭제 |
| 결제 처리 위탁 내역 | [대표 결정 Q2] | 위탁 업체 보관 기준을 확인한 뒤 확정 |

## 4항 목록에 더할 줄 (제3자 제공·처리 위탁·국외 이전)

- 처리 위탁(결제 처리): 포트원·토스페이먼츠(국내 결제 대행). 보내는 항목: 주문 금액, 주문 번호. 카드 번호는 손님 브라우저에서 결제 대행사로 직접 가며, 우리 서버에는 오지 않습니다. (확인 필요: 수탁 사업자 정식 명칭·재위탁 여부)
- 온라인 주문 내용은 해당 가게(사장님)에 전달됩니다. 이 경우 당사가 가게를 위해 처리하는 수탁자에 해당하는지 확인 필요 (문의·예약과 같음).

## 6항 목록에 더할 줄 (쿠키·브라우저 저장소)

- 온라인 주문 문자 인증을 통과하면 그 가게의 주문 주소에만 쓰이는 "기기 기억" 쿠키(`pv_가게키`)를 90일 둡니다(HttpOnly·Secure·SameSite=Lax). 값은 전화번호·만료 시각·위조 방지 서명이며, 같은 기기·같은 번호로 다시 주문할 때 문자 인증을 생략하고, 그 가게의 "내 스탬프" 화면(도장·쿠폰)을 보여 주는 데만 씁니다. 브라우저 쿠키를 지우면 다음 주문 때 다시 인증합니다.
