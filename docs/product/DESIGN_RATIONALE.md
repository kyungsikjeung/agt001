## 2. 핵심 트레이드오프 10선

| # | 선택지 A (버림) | 선택지 B (채택) | 왜 B인가 | 대가 |

| T-4 | React Native 앱 | PWA 1차 | 마감 2일 + 1인 검증. 설치·오프라인은 PWA로 충분 | 푸시·스토어 배포는 베타 뒤 |

## 4. 시니어 회고 (다음에 다르게 할 것)

1. **패키지 분리를 첫날에.** T-5의 1주 갈아엎기는 "빨리 보여주기"와 "기반"을 바꾼 대가. 데모용 단일 파일은 3일을 넘기면 안 된다.
2. **계약서(BND)를 코드와 함께 리뷰에.** `contracts/` 3종 stale은 "문서 따로, 코드 따로"의 결과. 계약 변경은 코드 PR에 필수 포함으로.
3. **README에 복사 금지 (P-6).** 운영 HEAD·테스트 수 같은 휘발 정보는 STATUS에만. README는 링크 허브.
4. **평가는 첫주에.** T2·T3를 9/26이 아니라 9/22에 돌렸으면 엔진 결함 16건을 4일 일찍 잡았다.
5. **NIM 한도 모니터링을 Day 1에.** r6 한도 소진 대기는 무료 티어의 예정된 수순. 한도 게이지를 대시보드에.
