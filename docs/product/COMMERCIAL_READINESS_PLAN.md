# 상업 이용 제한 걷어내기 + 오픈까지 비용 (2026-09-26)

> 계기: 대표 요청 "상업 사용을 제한하는 모델을 걷어내고 오픈할 순차 통합 계획", "오픈까지 테스트 포함 비용 리서치".
> 일정 전제: D47(10/17 비공개 베타 검증, 11/14 정식 오픈 목표). 외부 사실은 2026-09-26 확인, 확인 못 한 것은 "확인 못 함".

## 0. 5줄 요약

1. **서비스의 AI 호출이 거의 전부 NVIDIA 무료 체험판(NIM Trial)이다**: 대화·추출·검토·컨셉·문구·임베딩·음성 인식·음성 합성·코드생성. 체험판 약관은 "평가 목적만, 상업 환경은 별도 구독"이라 **정식 오픈 전에 전부 바꿔야 한다**(R-b).
2. 모델 **가중치**(Nemotron)는 상업 이용이 되지만, 우리가 쓰는 **호스팅 무료 API**가 막혀 있다. 직접 운영(NIM)은 NVIDIA AI Enterprise(GPU당 연 4,500달러)라 우리 규모에 맞지 않는다.
3. **순서**: A 호출 한곳 모으기·코드생성 제거 → B 대화 모델 비교·교체(시뮬레이션으로 합격 확인) → C 임베딩 → D 음성 → E 카카오 알림 → F 전체 회귀 → 오픈.
4. **평가·테스트용 호출(가상 사장님·채점)은 체험판 약관의 "평가"에 해당**해 무료로 계속 써도 된다. 돈이 드는 건 "실제 서비스에 쓸 후보 모델"뿐이다.
5. **오픈까지 현금 비용 추정 약 100~200달러(약 14만~28만 원)** + 도메인 + (선택) 법률 검토. 서버는 무료 계층이라 0원.
