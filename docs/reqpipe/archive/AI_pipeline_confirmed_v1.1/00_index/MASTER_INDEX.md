## 2. 핵심 확정 사항 요약

- **프로세스** 12단계 5게이트, 루프백 계층 판정은 규칙표 12케이스로 고정(LLM 판정 금지)
- **채널** CLI 단독. 고객 질문은 카카오톡 링크 전달, 내부는 단일 승인자
- **에스컬레이션** L0→L1→L2→L3 = 4h / 24h / 48h, 업무시간 기준 정지 적용
- **수락 기준** AC 100% + 신규코드 라인 커버리지 70%, 측정 실패는 fail-closed
- **모델/추론** Nemotron 계열 Hermes, 호스티드 엔드포인트 유지(D21-A), self-host는 조건부 전환
- **실행 호스트** P0 로컬 PC 단독(D25-A). 타이머는 벽시계 기준 필수
- **기밀 등급** 사내 체계 부재 → C0/C1/C2 신설, 미지정 입력 기본값 C1
- **외부 송신** P0 한정 전면 허용 + 사후 감사(D20-C). 단 하드 금지 3범주(개인정보/크리덴셜/고객사 실명+계약조건)는 모드와 무관하게 차단
- **게이트 강제** `TransportPort.send(req, decision)` — Decision 필수 인자(D29-A)

## 3. 다음 단계 (S3 아키텍처)
